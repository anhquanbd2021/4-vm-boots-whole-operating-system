Isolation Under Glass · namespaces × cgroups

A container is a process, not a small VM.

Toggle the kernel's two controls one at a time. Namespaces mask what the process can see; cgroups leash what it can use; and the shared kernel is why there is nothing to boot.

Safe educational demo. A teaching model of Linux internals — no real namespaces, no real isolation, nothing leaves your browser.

Lab 1 · the visibility mask

Namespaces — what it can see

Each switch is one kernel mask. Turn them all off and the "container" sees the whole host — which is exactly what an unmasked process is.

Lab 2 · the resource leash

cgroups — what it can use

Each tick the process asks for memory and CPU. The kernel doesn't negotiate: over memory → OOM-killed; over CPU → granted less, so the work stretches.
